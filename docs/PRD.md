# 图片与 PDF 本地转换 v1.1 PRD与实施方案

## 一、产品目标

交付一款无需安装、完全离线、单 EXE 运行的 Windows 图片转 PDF / PDF 转图片工具，面向普通办公、表格材料、扫描件及批量转换。

成功标准：

- 图片完整进入页面，不裁剪、不拉伸。
- 普通 JPEG 导出不再重复解码和压缩。
- 300 张图片可稳定处理，界面不冻结、内存不无限增长。
- 支持文件、文件夹和拖入三种导入方式。
- 支持合并 PDF 与一图一个 PDF，并可预先选择输出路径。
- 文字水印、清晰度和全部现有功能免费可用。
- 最终可直接发布到 GitHub，采用 MIT 许可证。
- PDF 可逐页转换为 PNG 或 JPEG，支持批量、页码范围和三档分辨率。

![最终UI原型](../design/ui-concept-image2-v3-watermark.png)

原型布局定稿。默认质量文案为“推荐/快速 · 智能处理”，辅助说明为“JPEG原图直嵌；PNG/BMP 150 DPI”，不宣称始终是最小文件。实际界面一次只展开当前点击的菜单，原型中同时展开菜单仅用于展示功能。

## 二、功能需求

### 2.1 图片与页面

- 支持 JPG/JPEG、PNG、BMP；不支持 TIFF、HEIC、WebP、GIF。
- 支持“添加文件”“添加文件夹”及拖入文件或文件夹。
- 文件夹只读取当前层，按文件名自然升序加入，不递归子文件夹。
- 自动跳过重复路径；非图片和损坏文件给出汇总提示。
- 保留 A3、A4、A5、B4、B5、Letter、Legal，默认竖向 A4。
- 保留横图自动转正、0/5/10 mm 边距、单图旋转、拖动重排、排序、删除、清空、点击放大预览。
- 300 张图片导入后先显示卡片占位，缩略图异步生成，禁止同步重绘全部图片造成界面冻结。

### 2.2 水印

- 水印模式为“无水印 / 自定义 / 默认水印”，全部免费，默认选择“无水印”。
- 默认水印固定为“仅供参考”、18% 透明度、45° 倾斜、全页平铺、应用全部页面。
- 自定义水印支持 1～64 个字符、5%～60% 透明度、-45°/0°/45°、居中/平铺/右下角三种布局；颜色固定浅灰，字号自动适配。
- 自定义文字为空时禁止导出并提示。
- 缩略图和大图预览必须显示最终水印效果。
- 水印作为独立 PDF 覆盖层写入，不重新压缩已直嵌的 JPEG。
- v1 不支持图片水印、字体选择、彩色水印及单独页码范围。

### 2.3 输出、命名与路径

- 导出方式保留“合并为一个 PDF”和“一图一个 PDF”。
- 合并模式支持选择具体 PDF 文件，或选择文件夹后按合并文件名自动生成 PDF。
- 一图一个 PDF 自动切换为文件夹输出，并禁用单文件模式。
- 保留逐图命名、批量生成编号、非法字符替换及同名自动追加序号。
- 自动生成的文件不得静默覆盖已有文件；追加“(2)”“(3)”。
- 记住最后一次成功输出目录及文件/文件夹模式，保存到 `%LocalAppData%\ZenthZhang\ImageToPdf\settings.json`；不记录源图片路径。
- 配置缺失或损坏时回退到用户“文档”目录，不影响启动。
- 导出使用临时文件完成后原子替换；合并导出失败或取消时不留下半成品，一图一个 PDF 保留已经完成的文件。

### 2.4 界面、署名与设置

- 标题栏直接使用 `assets/app.ico`，不重新绘制图标。
- 删除无实际内容的三个点“更多”入口。
- 右上角增加设置齿轮，设置窗口只包含：
  - 添加/移除当前用户“发送到”右键入口；
  - 版本、MIT 许可证、开发者及 GitHub 地址。
- 首次启动且尚未添加入口时显示一次简短引导，用户点击“一键开启”后添加；选择“暂不设置”后不重复打扰。
- 不自动修改系统右键菜单，必须由用户主动操作；设置页始终保留添加与移除入口。
- 页脚显示：`本地处理 · 不上传图片 · 免费开源 · 由 ZenthZhang 开发`。
- “关于”窗口中的项目名称链接到 <https://github.com/TrendPioneerAI/image-to-pdf>。

### 2.5 PDF 转图片（v1.1）

- 主界面顶部提供“PDF 转图片”入口；直接拖入 PDF 或以 PDF 作为启动参数时自动进入该功能。
- 图片与 PDF 功能采用同一主窗口内的预创建页面切换，不创建第二个顶层窗口；PDF 页左上角提供返回入口，返回后恢复原有图片和设置，切换目标为人眼近乎即时且无闪屏。
- 支持一次添加多个 PDF、选择当前层文件夹及直接拖入；重复路径自动跳过。
- 文件列表异步显示页数、大小和位置；损坏、加密或系统无法渲染的 PDF 标记为不可读，批量导出时跳过并汇总提示。
- 默认转换全部页面；支持 `1-3,5` 格式的页码范围。超过某个 PDF 总页数的页码忽略，若该 PDF 没有任何有效选中页则跳过并提示。
- 输出格式为 PNG 或 JPEG。PNG 为默认无损格式；JPEG 默认质量 92，可在 50～100 之间调整。
- 输出分辨率为 150 / 220 / 300 DPI，默认 150 DPI“推荐/快速”。页面像素超过 1 亿时停止该页并提示降低 DPI，避免异常内存占用。
- 输出目录必须预先指定；文件名为 `PDF名_第001页.ext`，非法字符替换，同名自动追加 `(2)`、`(3)`，不覆盖已有文件。
- 转换在后台逐页执行，界面保持可移动并持续更新进度；支持取消，已完成图片保留，当前页临时文件清理。
- 文件夹读取仅限当前层，不递归；v1.1 不支持 PDF 密码输入、页面裁剪、颜色模式调整或矢量导出。

## 三、质量档位与技术方案

| 档位 | JPEG 处理 | PNG/BMP 及回退处理 | 默认 |
|---|---|---|---|
| 推荐/快速 · 智能处理 | 原始 JPEG 字节直接嵌入 | 150 DPI、JPEG 质量 78 | 是 |
| 标准（220 DPI） | 重采样并以 JPEG 质量 86 编码 | 220 DPI、JPEG 质量 86 | 否 |
| 精细打印（300 DPI） | 重采样并以 JPEG 质量 92 编码 | 300 DPI、JPEG 质量 92 | 否 |
| 无损（高级） | 原始 JPEG 直接嵌入 | 原始分辨率 Flate 无损压缩 | 否 |

所有档位均禁止生成超过源图片实际像素的重采样位图。

实施要点：

1. 扩展 PDF 写入器，常规 1 或 3 通道、8 位且结构完整的 JPEG 通过 `DCTDecode` 从源文件流式写入；页面方向、EXIF 方向、手动旋转、边距和缩放通过 PDF 变换矩阵实现。
2. CMYK、损坏或无法安全解析的 JPEG 回退到当前档位的重采样路径，不错误直嵌。
3. 300 DPI 使用 JPEG 92，移除其默认逐字节 RGB 无损压缩。
4. PNG、BMP 及需要重编码的页面采用有界并行：
   - 8 核及以上使用 4 个工作线程；
   - 4～7 核使用 2 个；
   - 低于 4 核使用 1 个；
   - 缓冲页面数量不得超过工作线程数，写入顺序始终与图片顺序一致。
5. Unicode 水印先用系统中文字体渲染成可复用灰度遮罩，再作为 PDF 图像遮罩和透明覆盖层叠加；接收方无需安装相同字体。
6. 缩略图使用独立的有界后台队列和缓存，优先处理当前可见卡片。
7. 保持单 EXE 和无第三方运行库；不引入联网、遥测或云端依赖。
8. PDF 转图片使用 Windows 10/11 自带 `Windows.Data.Pdf` 渲染器；PNG 直接落盘，JPEG 仅对当前页做一次质量可控编码，逐页原子写入且峰值内存不随总页数增长。

内部接口：

- `QualityPreset`：`SmartFast / Standard / FinePrint / Lossless`。
- `WatermarkMode`：`None / Custom / Default`。
- `WatermarkOptions`：文字、透明度、角度和布局。
- `OutputTargetMode`：`File / Folder`。
- `ExportOptions` 包含水印和输出目标设置。
- `PreparedPage` 分离页面准备与按序 PDF 写入。
- 不新增外部 API 或网络接口。

## 四、验收与测试

### 4.1 旧版基线记录

| 现有档位 | 三张 2480×3508 图片耗时 | PDF 大小 |
|---|---:|---:|
| 150 DPI | 4.72 秒 | 0.48 MB |
| 220 DPI | 5.91 秒 | 1.17 MB |
| 300 DPI 无损 | 22.57 秒 | 20.22 MB |

### 4.2 验收标准

- 在同一电脑、同一数据集、预热后取三次中位数；包含 240 张 JPEG 和 60 张 PNG 的默认档导出，相比旧版至少提升 4 倍。
- 300 张图片导入和导出期间窗口可移动、可取消，进度持续更新；取消操作 1 秒内响应。
- 300 张 2480×3508 图片测试时，峰值内存不超过 768 MB 且不随页数持续增长。
- JPEG 快速档从 PDF 提取出的 DCT 数据与源 JPEG 字节 SHA-256 一致，证明没有二次压缩。
- PNG/BMP 快速、标准、精细和无损档分别验证 DPI、编码方式、页面尺寸及无放大规则。
- 无水印输出不得出现任何覆盖内容；默认和自定义水印需在缩略图、大图预览及最终 PDF 中一致。
- 中文、英文、数字和特殊字符水印在另一台 Windows 电脑上正常显示。
- 验证 EXIF 八种方向、自动横图转正、手动旋转、横竖纸、所有纸型及三档边距。
- 验证合并/逐图导出、文件/文件夹路径、同名处理、路径记忆、原子写入及取消恢复。
- 使用 PDF 渲染工具逐页截图比对，确认无裁剪、无拉伸、顺序正确、文字和印章可辨认。
- 构建后确认 EXE 使用原始 `app.ico`，无额外 DLL，断网环境可运行。
- 验证 PDF 转图片的全部页/页码范围、PNG/JPEG、150/220/300 DPI、批量文件、当前层文件夹、拖入、重复路径、同名处理、损坏文件、取消和临时文件清理。
- 在 GUI 中载入三页测试 PDF 后，应异步显示“1 个 PDF · 3 页”，导出按钮可用且控件在 Windows 缩放下无压盖。
- 图片页与 PDF 页预创建后的同窗换页应在 500 ms 内完成，不新建顶层窗口；返回后图片列表和设置保持不变。

## 六、边界

Windows 10/11、.NET Framework 系统编译环境、A4 竖向和无水印为图片转 PDF 默认值；PDF 转图片默认 PNG、全部页面、150 DPI。不包含 OCR、PDF 编辑、PDF 密码输入、递归目录、在线升级、安装程序或付费功能。
